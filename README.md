# EV-Population-Classification

Proyek ini adalah implementasi Machine Learning dasar untuk memprediksi jenis kendaraan listrik berdasarkan spesifikasinya. Tujuan utama dari proyek ini adalah mengklasifikasikan secara otomatis apakah sebuah kendaraan termasuk dalam kategori BEV (Battery Electric Vehicle - 100% listrik) atau PHEV (Plug-in Hybrid Electric Vehicle - kombinasi baterai listrik dan bensin).

Rincian Proyek:
Dataset: Menggunakan data publik Electric_Vehicle_Population_Data.csv yang berisi informasi populasi kendaraan listrik.
Fitur Data yang Dianalisis: Tahun Pembuatan (Model Year), Merek Mobil (Make), dan Jarak Tempuh Listrik (Electric Range).
Algoritma Model: Random Forest Classifier, yaitu metode klasifikasi yang menggunakan banyak "pohon keputusan" untuk menghasilkan tingkat akurasi yang tinggi.
Alat & Teknologi: Proyek ini dibangun sepenuhnya menggunakan Jupyter Notebook dengan bahasa pemrograman Python, dibantu oleh library Pandas (untuk pembersihan data) dan Scikit-Learn (untuk proses Machine Learning).
